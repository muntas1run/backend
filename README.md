# Little Lemon Restaurant API - Capstone Project

Данный проект представляет собой REST API для ресторана Little Lemon, разработанный с использованием Django REST Framework и СУБД MySQL.

## 🚀 Основные критерии проверки (Для рецензентов)

1. **Статический контент:** Приложение обслуживает статические HTML-страницы.
2. **База данных:** Подключение настроено на MySQL.
3. **Аутентификация:** Реализована регистрация и авторизация пользователей через Djoser (Token Authentication).
4. **Тестирование:** В проект включены модульные тесты для моделей и представлений.

---

## 🔀 Эндпоинты API для тестирования в Insomnia

Используйте базовый URL (например, `http://127.0.0.1:8000/`), чтобы протестировать следующие пути:

### 🔑 1. Аутентификация и пользователи (Djoser)
* `POST /auth/users/` — Регистрация нового пользователя.
* `POST /auth/token/login/` — Получение токена авторизации (Token Authentication).
* `POST /auth/token/logout/` — Отзыв токена (Log out).

### 🍽️ 2. Меню ресторана (Little Lemon Menu API)
* `GET /api/menu-items/` — Получить список всех блюд (доступно всем).
* `POST /api/menu-items/` — Добавить новое блюдо (только для администраторов/авторизованных).
* `GET /api/menu-items/<id>` — Получить информацию о конкретном блюде.
* `PUT/DELETE /api/menu-items/<id>` — Изменение/удаление блюда.

### 📅 3. Бронирование столов (Booking API)
* `GET /api/booking/tables/` — Просмотр всех бронирований.
* `POST /api/booking/tables/` — Создание нового бронирования стола.
